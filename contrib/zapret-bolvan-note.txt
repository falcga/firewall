На Raspberry Pi нужен именно upstream https://github.com/bol-van/zapret (или zapret2, см. readme о ветках).
Flowseal — главным образом Windows; его *.txt нужны здесь только как содержание списков.

После сборки см. файлы во state/generated/:
  zapret-hostlist.txt
  zapret-hostlist-exclude.txt
  zapret-ip.txt
  zapret-ip-exclude.txt

В параметрах nfqws/tpws укажите --hostlist / --hostlist-exclude или интеграцию через ipset (quick_start_linux).
Точную команду нужно брать из install_easy.sh вашей версии — у разных сборок синтаксис nft отличается.

Если хотите использовать ipset-блок Zapret только для выбранных IP, подсовывайте zapret-ip.txt вместе с утилитой ipset из комплекта bol-van (см. раздел docs про ipset и ip2net).
